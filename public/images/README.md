# /public/images

Drop your project images here.

Supported formats: `.png`, `.jpg`, `.jpeg`, `.webp`

Expected filenames (matching `src/data/projects.js`):

- project-1.png
- project-2.png
- project-3.png
- project-4.png
- project-5.png

To use a different filename or format, just update the `image` path for that
project in `src/data/projects.js` — e.g. `/images/project-1.webp`.
